# Shop

Shop content and progression dependencies.

## Shop Items

| Item | Cost (credits) | Effect | Unlock |
|---|---:|---|---|
| Municipal Dynamo Contract | 1000 | Unlocks `Municipal Dynamo` build (`+2.5 energy/s`) | Available from start |
| Access to the Public Library | 1500 | Unlocks the Research panel | Available from start |
| Prospecting Pickaxes | 3500 | Unlocks advanced ore industry planning tier | Requires Public Library access |
| Bessemer Converter License | 6200 | Unlocks steel industry planning tier | Requires Prospecting Pickaxes |

## Notes

- Shop visibility is progression-based: locked entries are hidden until requirements are met.
- Purchased entries remain visible and marked as owned.
