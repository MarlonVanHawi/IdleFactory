# Unlock Progression

This page tracks what becomes available through progression.

## Start of a New Save

### Available Immediately

- Build: `Warehouse`, `Market`, `Splitter`, `Merger`
- Build: `Coal Mine`, `Woodcutter`
- Shop: `Municipal Dynamo Contract`, `Access to the Public Library`

### Locked at Start

- Build: `Municipal Dynamo` (requires shop purchase)
- Build: `Sawmill` (requires `wood >= 30`)
- Build: `Iron Mine` (requires `Prospecting Pickaxes`)
- Build: `Iron Smelter` (requires `Prospecting Pickaxes` + `iron ore >= 24`)
- Build: `Copper Mine` (requires `Prospecting Pickaxes` + `iron plate >= 14`)
- Build: `Copper Smelter` (requires `Prospecting Pickaxes` + `copper ore >= 22`)
- Build: `Wire Mill` (requires `Prospecting Pickaxes` + `copper ingot >= 18`)
- Build: `Steelworks` (requires `Prospecting Pickaxes` + `iron plate >= 42`)
- Build: `Machine Shop` (requires `Prospecting Pickaxes` + `steel >= 22` + `copper wire >= 40`)
- Build: `Power Plant` (requires Municipal Dynamo Contract + `coal >= 45`)
- Research tab content (requires `Access to the Public Library`)
- Shop item: `Prospecting Pickaxes` (requires Public Library access)
- Shop item: `Bessemer Converter License` (requires Prospecting Pickaxes)

## Build Unlock Rules

| Buildable | Unlock Condition |
|---|---|
| Municipal Dynamo | Buy `Municipal Dynamo Contract` |
| Coal Mine | Available from start |
| Woodcutter | Available from start |
| Sawmill | Total wood in game `>= 30` |
| Iron Mine | `Prospecting Pickaxes` bought |
| Iron Smelter | `Prospecting Pickaxes` bought AND total iron ore `>= 24` |
| Copper Mine | `Prospecting Pickaxes` bought AND total iron plate `>= 14` |
| Copper Smelter | `Prospecting Pickaxes` bought AND total copper ore `>= 22` |
| Wire Mill | `Prospecting Pickaxes` bought AND total copper ingot `>= 18` |
| Steelworks | `Prospecting Pickaxes` bought AND total iron plate `>= 42` |
| Machine Shop | `Prospecting Pickaxes` bought AND total steel `>= 22` AND total copper wire `>= 40` |
| Power Plant | `Municipal Dynamo Contract` bought AND total coal `>= 45` |

## Shop Unlock Rules

| Shop Item | Unlock Condition |
|---|---|
| Municipal Dynamo Contract | Available from start |
| Access to the Public Library | Available from start |
| Prospecting Pickaxes | Requires `Access to the Public Library` |
| Bessemer Converter License | Requires `Prospecting Pickaxes` |

## Research Availability Rule

- The research panel becomes usable after buying `Access to the Public Library`.
- Individual research entries also have their own unlock requirements (see [[Research]]).
